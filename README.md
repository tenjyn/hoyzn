# Project Tracker

A simple dashboard for managing projects and recurring tasks. Built with React and Vite using Radix UI and Tailwind CSS.

## Prerequisites

- Node.js >= 18

## Installation

```bash
npm install
```

## Development

Start the development server with hot reloading:

```bash
npm run dev
```

## Production

Build the optimized production bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
